# 𝐓ʀᴇᴅᴀʀ 𝐊ᴀʀᴀɴ 👤
Paper-trading demo only. Starts with virtual ₹10,000 and has simulated BUY/SELL orders, 1D/1W/1M charts, login UI, reset balance, watchlist, dark/light UI, and owner branding.

Run:
npm install
npm run dev

This version does not connect to a broker, accept deposits, or place real trades. The login is demo-only.
